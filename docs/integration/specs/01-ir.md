# 01 — Database IR completo + climatizzatori

## Obiettivo
Portare il database IR da 309 file (solo TV) a un database completo con
climatizzatori, audio, DVD, proiettori e console, senza gonfiare il firmware.

## Requisiti
- Scaricare Flipper-IRDB (o irdb convertito in formato Flipper) e copiare i
  file `.ir` sulla microSD in `E:\ir`, preservando le cartelle per marca.
- Non cancellare i file già presenti in `E:\ir`; fondere e deduplicare.
- `IrMenu` deve leggere **sia LittleFS sia SD** e mostrare un solo albero,
  senza duplicati. Oggi se LittleFS ha `/ir` la SD non viene considerata.
- Categorie visibili: TV, Clima, Audio, DVD/Blu-ray, Proiettore, Console,
  Universale. Se una categoria non esiste, mostrarla solo quando ha file.
- La ricerca e i preferiti esistenti devono continuare a funzionare.
- Verificare che i file AC usino protocolli già supportati (NEC, Samsung,
  Kaseikyo/Panasonic, RC5/RC6, raw). Se serve, estendere il parser solo per
  i comandi mancanti, senza rompere i telecomandi esistenti.
- Il firmware non deve crescere più di ~5 KB: i dati stanno su SD.

## Accettazione
- Build `cardputer-adv-offensive` OK.
- Con SD inserita, il menu IR mostra le nuove categorie e almeno 2.000 file.
- Con SD assente, resta il database LittleFS attuale.
- `REPORT.md` con conteggio file, dimensioni SD, dimensione firmware, test.

## Attenzione
- Non toccare `src/main.cpp`, `platformio.ini`, `include/ModuleFlags.h`.
- Non sovrascrivere `E:\BruceIR` né altre cartelle di altri firmware.
- Il filesystem SD è FAT32: nomi brevi e nessun carattere strano.
