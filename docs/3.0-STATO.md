# OrbitOS 3.0 — stato del port

Base: ESP-IDF 5.4, C++17, Cardputer ADV (ESP32-S3FN8, 8 MB, no PSRAM).
Il firmware 2.x (Arduino/PlatformIO) resta in `src/`, `platformio.ini`, `.pio/`.
Build verificata: 1.640.816 B, 42% libero nella partizione app.

## Portato e compilato

| Area | Note |
|---|---|
| Home, UI, temi, rotazione, display, batteria ADC | carosello 9 voci: Store, Giochi, Media, Bluetooth, Rete, Analisi RF, Strumenti, Zorbo, Impostazioni |
| Giochi nativi (19) + Wren store | punteggi in NVS `orbit-scores` |
| Store giochi | catalogo ECDSA P-256, SHA-256, download su LittleFS; giochi 2.x su `/sd/games` |
| Impostazioni | WiFi, tema, luminosità, rotazione, nickname, storage, SD, avviso legale, info |
| Chat BLE | protocollo 2.x invariato |
| SD browser / screenshot BMP / backup impostazioni | `/sd` e `/littlefs` |
| Zorbo | NVS `orbit-mascot`, punti solo dopo legalWarning |
| Musica | ES8311 + I2S, MP3 minimp3 e WAV, album/cover, player |
| BLE | scanner + spam Random/Apple/Samsung/Google/Windows, legalWarning |
| WiFi | scanner, AP info, deauth target/flood, beacon spam, evil twin+portal, canali |
| IR | database Flipper `.ir`, NEC/Samsung/Sony/RC5/RC6/LG/JVC/Kaseikyo/RCA/raw, jammer |
| Strumenti | orologio, note, calcolatrice, TOTP, QR, info, SD browser |

## Test hardware via seriale (COM5)

- display 135x240 PASS, framebuffer 16bpp PASS
- ES8311 a 0x18 PASS, playback MP3 reale 1,5 s PASS
- NVS PASS, impostazioni 2.x importate (`bright=128 theme=0 rot=0 nick=lore_1`)
- microSD PASS (14891 MB, musica 70 file, IR 2257 file, games 5)
- LittleFS PASS (games 3)
- WiFi scan PASS (2 reti), connessione STA PASS (IP 192.168.1.9)
- BLE scan PASS (4 dispositivi)
- frame raw deauth/beacon PASS con binario patchato
- heap dopo mount+radio: 143 KB
- Wren 2048/breakout/flappy avviati da `/littlefs/games` con ~164 KB liberi;
  framebuffer 16bpp mantenuto (niente flicker, colori pieni all'uscita)
- giochi nativi in landscape: scelta automatica della rotazione con
  `width > height`, ripristino della rotazione utente all'uscita
