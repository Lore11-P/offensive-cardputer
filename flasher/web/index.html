CardputerFirmware v1.0.0 offensiva

Firmware modulare: BLE, Wi-Fi, 307 telecomandi IR, giochi, file browser SD e impostazioni. Funzioni offensive abilitate per test autorizzati.

Browser non supportato. Usa Chrome o Edge su desktop. Apri questa pagina via http://localhost o HTTPS.
  1. Collega la Cardputer al PC con un cavo USB dati.
  2. Premi Installa firmware e seleziona la porta seriale.
  3. Se la porta non compare, tieni premuto G0 e reinserisci il cavo.
  4. Al termine scollega e riavvia: il firmware parte con la splash screen.
Offsets: 0x0 bootloader, 0x8000 partizioni, 0x10000 app, 0x410000 LittleFS (3,9 MB). Flasher web basato su ESP Web Tools. Uso consentito solo su dispositivi propri; rispetta le normative radio locali.
